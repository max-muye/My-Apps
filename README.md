# My-Apps

This is my collection of random stuff.

It is a personal workspace for small apps, experiments, scripts, graphics, sounds, files, and ideas that I want to keep in one place. Some projects may be unfinished, weird, practical, or just made for fun.

## What you may find here

- Small macOS and Windows experiments
- Swift, C++, HTML, and command-line projects
- Utility scripts and automation
- Images, icons, animations, and audio
- Test files and prototypes
- Things I made while learning

## Status

This repository is intentionally informal. Contents may change often, and not every project is polished or documented.
