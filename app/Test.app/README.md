# Test

A native macOS application written in Swift using AppKit.

## Requirements

- macOS 12.0 or later
- Swift compiler
- Apple Command Line Tools

## Project Structure

```text
Test.app/
├── README.md
├── compile.sh
├── main.swift
└── Contents/
    ├── Info.plist
    └── MacOS/
        └── Test
```

## Build

Run:

```bash
chmod +x compile.sh
./compile.sh
```

## Run

```bash
open .
```

## Features

- Native macOS window
- Clickable button
- Alert dialog
- Resizable window

1.0.0
